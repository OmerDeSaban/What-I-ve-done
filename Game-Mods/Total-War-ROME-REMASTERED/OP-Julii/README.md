# OP Julii

A personal **Total War: ROME REMASTERED** campaign mod that turns the Julii into a deliberately overpowered Roman faction while also applying several global campaign, economy, recruitment, diplomacy, and quality-of-life changes.

The project packages the previously edited base-game files into a Feral launcher-compatible mod folder so the vanilla installation no longer needs to be modified directly.

## Current Status

The launcher folder and `modinfo.json` are prepared. One machine-generated file is intentionally not included yet: `filelist.json`.

ROME REMASTERED's launcher generates `filelist.json` as the mod manifest. After copying the mod into the game's **My Mods** directory, select **OP Julii** in the Feral launcher and use **Regenerate Manifest**. The generated `filelist.json` should then be copied back into this repository and committed alongside `modinfo.json`.

Do not create a blank `filelist.json`. Until the launcher generates a valid manifest, launching the entry can fall back to vanilla data rather than loading the mod.

## What the Mod Changes

### Julii Starting Campaign

`descr_strat.txt` substantially expands the Julii starting position:

- Julii begin with four regions instead of the original two: Etruria, Umbria, Apulia, and Sicilia Romanus.
- The starting settlements are heavily developed and have much larger building sets.
- Starting populations are raised to `9509` in the four Julii settlements.
- The faction begins with a much larger collection of characters, armies, and units.
- Brigand and pirate spawn values are reduced to `0`.
- Every campaign-map resource quantity in the file is set to `3`.

The starting treasury remains `5000` denarii.

### Buildings and Recruitment

`export_descr_buildings.txt` heavily accelerates Roman development:

- Building construction times are reduced to `1` turn.
- Building construction costs are reduced to `1` denarius.
- Roman recruitment availability is greatly increased across many recruitment chains.
- A broad set of settlement capabilities and bonuses is increased, including economic, population, public-order, health, farming, trade, law, and morale effects.

`descr_cultures.txt` also makes several Roman infrastructure and agent costs effectively free and adjusts settlement-level limits for multiple cultures.

### Units

`export_descr_unit.txt` makes many Roman units effectively free to recruit and maintain:

- recruitment time is reduced to `0` for the modified entries;
- recruitment, upkeep, weapon-upgrade, and armour-upgrade costs are reduced to `1`;
- existing custom-battle costs are retained;
- Julii ownership is added to the Velite Gladiator and Mirmillo Gladiator entries.

The affected entries include Roman infantry, cavalry, siege units, and ships.

### Julii Characters, Traits, and Ancillaries

`export_descr_character_traits.txt` adds a large set of Julii-specific triggers that grant strong positive traits to agents and characters. Many existing trait triggers are also amended to exclude `romans_julii`, protecting the faction from a range of normal unwanted trait outcomes.

`export_descr_ancillaries.txt` adds Julii-specific ancillary triggers for merchants, assassins, spies, diplomats, and family characters, including both creation-time grants and later checks that can restore missing ancillaries.

### Diplomacy and Trade

`feral_descr_reputations_and_relations.txt` strengthens several reputation and diplomacy effects, including long-term alliances, accepted ceasefires, accepted military assistance, and ally-of-an-ally relationships. Merchant-embargo income is also increased substantially.

### Building Text

`data/text/export_buildings.txt` replaces a large number of otherwise hidden placeholder building descriptions with usable text. This is useful because the modified building availability can expose building variants that the vanilla campaign normally never displays.

## Installation and First Test

Before testing, restore the eight directly edited files in the base game to their original versions. This is essential: otherwise the game can appear to be loading the launcher mod while it is actually still reading your old edits from the vanilla installation. You can either restore your saved originals or use Steam's **Verify integrity of game files** feature.

Copy this folder:

```text
launcher\OP_Julii
```

into:

```text
%LOCALAPPDATA%\Feral Interactive\Total War ROME REMASTERED\Mods\My Mods\
```

so the installed result is:

```text
%LOCALAPPDATA%\Feral Interactive\Total War ROME REMASTERED\Mods\My Mods\OP_Julii\
```

Then:

1. Open the ROME REMASTERED pre-game launcher.
2. Open the mod manager and select **OP Julii**.
3. Click **Regenerate Manifest** to create or update `filelist.json`.
4. Enable **OP Julii** and launch the Rome campaign.
5. Start a **new Imperial Campaign** to test the modified Julii starting position. Existing saves cannot retroactively receive the starting-map and starting-army setup from `descr_strat.txt`.
6. After the mod is confirmed working, copy the generated `filelist.json` from the installed `OP_Julii` folder back to `launcher/OP_Julii/filelist.json` in this repository and commit it.

Whenever any mod file is added or changed, regenerate the manifest again before testing.

## Repository Location

This project is intended to live in the **What I've Done** repository at:

```text
Game-Mods/
└── Total-War-ROME-REMASTERED/
    └── OP-Julii/
```

Only the modified mod files, metadata, manifest, and documentation should be committed. The backup archive of original game files should remain outside Git.

## Git Workflow

From the root of the **What-Ive-Done** repository, after copying this project into the path above and replacing the repository's root `README.md` with the updated version:

```powershell
git status
git add Game-Mods/Total-War-ROME-REMASTERED/OP-Julii README.md
git commit -m "Add Total War ROME REMASTERED OP Julii mod"
git push
```

After the first successful launcher test and manifest generation:

```powershell
git add Game-Mods/Total-War-ROME-REMASTERED/OP-Julii/launcher/OP_Julii/filelist.json
git commit -m "Add OP Julii launcher manifest"
git push
```
