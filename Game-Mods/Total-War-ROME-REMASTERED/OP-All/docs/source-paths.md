# Source Paths

The mod mirrors the original Total War: ROME REMASTERED file locations underneath its own `data` directory.

| Mod file | Original game path |
| --- | --- |
| `data/text/export_buildings.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\text\export_buildings.txt` |
| `data/world/maps/campaign/imperial_campaign/descr_strat.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\world\maps\campaign\imperial_campaign\descr_strat.txt` |
| `data/descr_cultures.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\descr_cultures.txt` |
| `data/export_descr_ancillaries.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\export_descr_ancillaries.txt` |
| `data/export_descr_buildings.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\export_descr_buildings.txt` |
| `data/export_descr_character_traits.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\export_descr_character_traits.txt` |
| `data/export_descr_unit.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\export_descr_unit.txt` |
| `data/feral_descr_ai_personality.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\feral_descr_ai_personality.txt` |
| `data/feral_descr_reputations_and_relations.txt` | `Total War ROME REMASTERED\Contents\Resources\Data\data\feral_descr_reputations_and_relations.txt` |

The original unmodified game files are intentionally **not** part of this repository. Only the modified files required by the mod should be committed.
